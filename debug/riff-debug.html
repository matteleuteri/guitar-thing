Riff ear check

Every button here runs the same code path as the app — parseRiff, RiffTransport and playVoicing — so what you hear is what Riff mode does. The numbers printed under each case are the scheduling ground truth, already proven by npm test; they are here so your ears and the measurements can be compared. Only the judgements need you: does it sound like a guitar, and does it sound musical.

1 · The default riff, exactly as shipped

The textarea default from riff.html: a C Am F G chord line plus an 8-note melody, 96 bpm, strum 55 ms, release 400 ms, looping.

2 · Note length / damping (the newest, least-tested feature)

Same chord, same strum, only the note length changes. Listen for: does ring overlap into the next hit, and do the shorter ones end like a real note stopping — or do they click, chop abruptly, or sound like a cut-off sample?

—

3 · Strum width (0 must be one instant)

One open C, played three times. Listen for: 0 should be a single solid chunk; 55 a natural hand-rolled strum; 300 a slow arpeggio. If 0 still sounds rolled or smeared, the jitter fix regressed.

—

4 · Kit A/B

The same chord on each engine. Useful if the steel kit ever sounds wrong and you want to know whether it is the kit or the engine.
